
# SIH 2026 - Civic Problem Classification & Solution Platform (Backend)

An automated backend pipeline integrating Express.js, PostgreSQL (Supabase), and NLP categorization to streamline civic problem reporting and HEI proposal allocations.

---

## 🛠 Tech Stack
- **Runtime:** Node.js / Express.js
- **Database:** Supabase (PostgreSQL with Row-Level Security)
- **AI Engine:** Python NLP Classifier (TF-IDF / Keyword Fallback Engine)
